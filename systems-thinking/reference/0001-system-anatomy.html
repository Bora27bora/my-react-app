System Anatomy

Definition

A system is an interconnected set of elements that is coherently organized in a way that achieves something. It is more than the sum of its parts.

The three components

Component What it is Example (tree / university)
Elements The "things" — often visible, but can be intangible (pride, morale, trust). Roots, trunk, leaves · Students, professors, buildings, school pride
Interconnections Relationships holding elements together — often information flows as much as physical ones. Water-pressure signals between roots/leaves · Admissions standards, grades, money flows
Function / Purpose What the system achieves — deduced from behavior, not from what it claims. Grow, reproduce, survive · (Allegedly) communicate knowledge

Is it a system? (4-question test)

  1. Can you identify parts?
  2. Do the parts affect each other?
  3. Do the parts together produce an effect different from each part alone?
  4. Does that effect persist over time, across varying circumstances?

All four "yes" → it's a system. (Sand on a road fails the test; a football team passes it.)

The core principle

"Purposes are deduced from behavior, not from rhetoric or stated goals." — Every system has a stated purpose and a revealed purpose (what it actually, repeatedly produces). Watch for the gap between them.
