# Systems Thinking — Teaching Workspace

A learning workspace for *Thinking in Systems: A Primer* (Donella Meadows),
built with the [`/teach` skill](../.claude/skills/teach/SKILL.md).

## Where to start

Open [`lessons/0001-what-is-a-system.html`](./lessons/0001-what-is-a-system.html)
in a browser — that's Lesson 1.

## Layout

- `MISSION.md` — why you're learning this, and what success looks like
- `RESOURCES.md` — curated knowledge & community resources
- `GLOSSARY.md` — canonical terms, added once understood
- `NOTES.md` — your preferences and working notes
- `lessons/` — self-contained HTML lessons, one concept each, numbered in order
- `reference/` — compressed cheat-sheets/quick references tied to lessons
- `learning-records/` — created as insights and progress are recorded

## Continuing

To get the next lesson, run `/teach` and say what you'd like to learn next (or
just say you're ready to continue, and your progress in the book).
